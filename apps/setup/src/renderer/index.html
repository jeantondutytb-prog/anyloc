Anyloc Setup v0.2.3

Applique ta position GPS sur iPhone

Branche ton iPhone en USB, colle ton token depuis le dashboard, puis applique Marbella (ou toute autre position) directement sur ton téléphone.

1. Token appareil

Génère un code sur anyloc.io/dashboard/installation, puis colle-le ici.

Copie uniquement le code qui commence par anyloc_ (sans « Bearer »).

2. État USB

Vérification en cours...

3. Appliquer la position GPS

Choisis ta ville sur le dashboard Anyloc, puis clique ci-dessous. L'iPhone doit rester branché en USB pendant l'utilisation.

Installation native (optionnel)

L'app iOS native n'est pas encore disponible. En attendant, la simulation GPS via USB fonctionne avec Anyloc Setup.

Prérequis

  • Outils USB Mac : pip3 install pymobiledevice3
  • iPhone branché + « Faire confiance à cet ordinateur »
  • Mode développeur (après connexion USB, en bas de Confidentialité et sécurité)
  • Token appareil généré depuis le dashboard Anyloc
  • Position activée sur la carte du dashboard
