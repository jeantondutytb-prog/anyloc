En attendant l'app iOS

Si l'installation native n'est pas encore disponible, ouvre https://anyloc.io/web dans Safari sur ton iPhone. Connecte-toi, choisis ta position — ça fonctionne sans installer d'app.

Prérequis

  • Outils USB Mac : pip3 install pymobiledevice3
  • iPhone branché + « Faire confiance à cet ordinateur »
  • Mode développeur (apparaît après connexion USB, en bas de Confidentialité et sécurité)
  • Sinon : installe Xcode (App Store), ouvre-le, branche l'iPhone
  • Token appareil généré depuis le dashboard Anyloc
