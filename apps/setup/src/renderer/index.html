Anyloc Setup v0.3.0

Installe Anyloc sur ton iPhone

Branche ton iPhone en USB une seule fois pour installer l'app. Ensuite, tout se fait depuis ton iPhone — position et renouvellement via LocalDevVPN, sans repasser par l'ordi.

1. Token appareil

Génère un code sur anyloc.io/dashboard/installation, puis colle-le ici et dans l'app Anyloc sur ton iPhone.

Copie uniquement le code qui commence par anyloc_ (sans « Bearer »).

2. État USB

Vérification en cours...

3. Installer l'app iPhone

Clique ci-dessous pour installer l'app Anyloc sur ton iPhone. Ensuite, ouvre l'app sur ton tel, colle ton code, et choisis ta destination — tu n'as plus besoin de l'ordi.

4. Exporter le fichier de pairing

Envoie ce fichier sur ton iPhone par AirDrop, puis ouvre Anyloc → Importer le pairing.

Secours USB (optionnel)

Uniquement si l'installation de l'app échoue : applique la position GPS directement via USB en attendant.

Prérequis

  • Outils USB Mac : pip3 install pymobiledevice3
  • iPhone branché + « Faire confiance à cet ordinateur »
  • Mode développeur (après connexion USB, en bas de Confidentialité et sécurité)
  • Token appareil généré depuis le dashboard Anyloc
  • Abonnement Anyloc actif
